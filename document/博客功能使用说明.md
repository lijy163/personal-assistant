# 博客功能使用说明

## 页面入口

- 登录个人系统后，在“知识沉淀 → 博客管理”管理文章。
- 点击“访问博客”或博客管理页右上角按钮，新窗口打开公开博客 `/blog`。
- 公开博客不需要登录，只能查看状态为“已发布”的文章。

## 写作和发布

1. 进入博客管理，点击“写新文章”。
2. 填写标题、摘要、分类和标签；`slug` 不填写时由标题自动生成。
3. 使用 Markdown 编写正文，右侧实时显示安全渲染后的阅读效果。
4. 点击“插入图片”上传正文图片，系统会自动追加 Markdown 图片语法。
5. 可上传封面，也可填写 HTTPS 图片地址。
6. 保存为草稿，或选择“保存并发布”。已发布文章可随时下线后继续编辑。

编辑中的内容会延迟约 600 毫秒保存到当前浏览器的本地草稿。服务端草稿需要点击“保存草稿”后才会同步到其他设备。

## Markdown 能力

支持标题、列表、引用、表格、链接、图片、行内代码和代码块。原始 HTML 默认关闭，生成内容还会经过 DOMPurify 清洗；外部链接使用新窗口打开，以降低脚本注入和页面劫持风险。

## 图片限制

- 支持 JPEG、PNG、WebP 和 GIF。
- 单张图片最大 10 MB。
- 图片保存在 `app.storage.path/files/blog`，会包含在现有应用文件备份中。
- 图片 URL 使用随机令牌，不按数据库自增 ID 暴露。

## 导航结构

左侧导航重构为：首页、事务管理、知识沉淀、财务市场、系统管理。一级分类互斥展开，并在当前浏览器记住上次展开的分类；手机抽屉菜单使用同一结构。

## 部署

重新构建并部署后，Liquibase 自动执行 `016-create-blog-module.yaml`。无需新增容器或独立数据库；Nginx 现有 SPA 路由能够直接支持 `/blog` 与文章详情地址。
