# 开发日志沉淀使用说明

## 功能说明

- DevLog：保存一次开发任务的目标、核心修改、技术决策、问题解决方式、验证结果和精炼 Markdown，便于后续检索与复盘。
- PAT：给 Codex 推送脚本使用的最小权限令牌，只具有 `devlog:write` 权限。数据库只保存 SHA-256 哈希，明文仅在创建时显示一次。
- 推送脚本：读取人工或 Codex 生成的总结 JSON，补充 Git 项目名、分支、提交号和远程仓库地址，然后安全推送到系统。
- 列表与详情：在网页中按关键词搜索开发记录，并查看完整的任务上下文、决策和验证信息。

## 使用步骤

1. 登录系统，进入“开发沉淀 → 推送令牌”，创建令牌并立即复制。
2. 复制 `scripts/devlog-summary.example.json`，填写本次开发总结。不要填写密钥、环境变量、完整 Diff 或未经清洗的日志。
3. 在项目 Git 仓库中执行：

```powershell
$env:PERSONAL_ASSISTANT_PAT = "pa_pat_创建时显示的令牌"
.\scripts\push-devlog.ps1 -SummaryFile .\scripts\devlog-summary.example.json -ServerUrl http://localhost:8080
```

4. 进入“开发沉淀 → 开发记录”查看列表和详情。

相同总结在相同项目、分支、提交和发生时间下会生成相同指纹，重复推送不会创建重复记录。令牌泄露或不再使用时，应立即在页面撤销。
