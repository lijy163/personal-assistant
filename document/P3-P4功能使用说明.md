# P3/P4 功能使用说明

## P3：账单中心

账单中心用于把支付宝、微信或银行导出的 CSV、XLS、XLSX 流水整理为统一的个人收支数据。原始流水会保留，只有用户确认批次后才写入正式交易，重复文件和重复交易会被拦截。

使用顺序：

1. 在左侧进入“个人账单”，先创建现金、银行卡、支付宝或微信账户。
2. 按需创建收入/支出分类与关键词规则。
3. 选择账户和来源平台，上传账单文件并查看解析预览、重复项和错误项。
4. 确认预览无误后提交批次，系统生成正式交易。
5. 在交易列表中搜索、按月份查看、人工修正分类，或导出 CSV。

当前解析器识别常见中文表头，支持 UTF-8、GB18030、CSV 引号字段以及 XLS/XLSX。不同平台导出格式会变化，首次使用新的真实账单样本时应先核对预览，不能直接确认导入。

## P4：便携与综合分析

- “每日驾驶舱”汇总今日和逾期任务、待处理提醒、待确认收件箱/账单、近期开发记录、学习计划、月度收支和自选股资金流变化。
- “统一收件箱”接收一句话记录，通过可解释规则建议为任务、提醒、消费、学习或普通记录；建议必须由用户确认，不会静默创建其他业务数据。
- 顶部全局搜索覆盖快捷记录、任务、学习总结、开发记录、账单与股票，关键词至少输入两个字符。
- “自动报告”可手动生成周报或月报；相同用户、类型和周期重复生成时更新原报告，不产生重复记录。
- 调度管理可创建 `AUTO_REPORT` 任务，配置示例为 `{"type":"WEEKLY","userId":1}`；类型支持 `WEEKLY` 和 `MONTHLY`。
- 系统支持账单 CSV、开发记录 Markdown、学习记录 CSV 导出。
- Web 应用已提供 PWA 安装清单、离线外壳和移动端响应式导航；鉴权 API 响应不会写入离线缓存。

## 当前边界

- P1 AI 网关尚未开发，因此账单分类和收件箱建议当前使用本地规则，并保留人工确认。
- 自动报告当前基于确定性统计，不生成 AI 评价、投资建议或消费建议。
- PWA 已支持安装、响应式布局和有限静态资源离线访问，尚未接入浏览器 Push 推送。
- 行业资金流按当前用户自选股的 `industry` 字段聚合，属于自选范围视图，不代表全市场行业或概念板块数据。
- 支付宝、微信和各银行真实导出样本仍需在部署环境逐个平台联调。
